# Dino Evolution Script

A modular TypeScript Discord quest bot.

## تشغيل

```bash
npm install
cp .env.example .env
# ضع DISCORD_TOKEN داخل .env
npm run build
npm start
```

للتطوير:

```bash
npm run dev
```

البيانات حاليًا محفوظة في الذاكرة أثناء تشغيل البوت. أضف قاعدة بيانات لاحقًا إذا أردت حفظ التقدم بعد إعادة التشغيل.
